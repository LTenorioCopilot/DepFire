Prueba de concepto: Widget de Facebook (Page Plugin)

Este es un archivo aislado, separado del sitio principal, solo para validar que el widget carga bien antes de integrarlo a la landing.

Nota: este widget solo se renderiza correctamente si abres este archivo desde un servidor real (http/https) — abrirlo directo desde tu computadora (file://) puede que Facebook no lo cargue por restricciones de seguridad del navegador. Si no carga, prueba subiéndolo a un hosting de prueba o usa una extensión de "live server" local.

Cómo funciona: Facebook carga este contenido directamente desde sus servidores mediante su SDK de JavaScript (connect.facebook.net). No pasa por tu hosting de Azure.

Parámetros que puedes ajustar: data-width / data-height (tamaño), data-tabs="timeline" (qué muestra), data-small-header (versión compacta del encabezado).
